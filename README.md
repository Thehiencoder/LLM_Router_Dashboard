## Key Features

- **Side-by-Side Multi-Model Benchmarking:** Send a single prompt simultaneously to multiple frontier models and compare their outputs in responsive columns with Markdown formatting and syntax highlighting.
- **Docker-Ready Architecture:** Complete containerized deployment featuring lightweight multi-stage Nginx for frontend and Python 3.13-slim for backend, orchestrated via Docker Compose.
- **Microsecond Latency Precision:** Benchmarks elapsed API response times directly at the backend network boundary using Python's `time.perf_counter()`.
- **Granular Token Analytics:** Breaks down token metrics into **Input Tokens**, **Output Tokens**, **Total Tokens**, and accounts separately for **Reasoning / Thinking Tokens** generated by reasoning models (`o1`, `o3-mini`, `claude-3-7-sonnet-thought`).
- **Dual-Cost Financial Accounting:**
  - **Gemini Free Tier Recognition:** Correctly flags Google AI Studio free tier keys as **`$0.00 Actual Cost`** while calculating the nominal commercial list equivalent for true cross-vendor value comparisons.
  - **Pay-As-You-Go Precision:** Accurately bills paid models against official price-per-million token schedules.
- **Fault-Tolerant Concurrency:** Powered by Python 3.13 structured `asyncio.gather`. Each provider execution is isolated in an individual error boundary—if one vendor returns HTTP 429 (Rate Limit) or an invalid API key, the remaining models finish and display without interruption.
- **Provider Adapter Pattern:** Common abstract `BaseLLMProvider` decouples the routing layer from vendor-specific SDK semantics, allowing new LLMs (e.g. Mistral, Groq, DeepSeek, Ollama) to be integrated with zero frontend changes.
- **Zero-Credit Mock Mode:** Built-in simulation provider enables full UI development, automated testing, and product demonstrations without requiring funded API keys.

## Architecture & Design Principles

```
  ┌────────────────────────────────────────────────────────┐
  │              React + Vite + TypeScript                 │
  │   (PromptInput, ModelSelector, ResponseCards, Metrics) │
  └───────────────────────────┬────────────────────────────┘
                              │ POST /api/compare
                              ▼
  ┌────────────────────────────────────────────────────────┐
  │              FastAPI Backend Gateway                   │
  │     (Pydantic v2 Validation & Request Sanitization)    │
  └───────────────────────────┬────────────────────────────┘
                              │
                              ▼
  ┌────────────────────────────────────────────────────────┐
  │        ComparisonService (Async Concurrency Engine)     │
  │   - asyncio.gather with per-task try/except shielding  │
  │   - Master timer: time.perf_counter()                  │
  └───────┬───────────────────┬───────────────────┬────────┘
          │                   │                   │
          ▼                   ▼                   ▼
    ┌───────────┐       ┌───────────┐       ┌───────────┐
    │  OpenAI   │       │ Anthropic │       │  Gemini   │
    │  Adapter  │       │  Adapter  │       │  Adapter  │
    └─────┬─────┘       └─────┬─────┘       └─────┬─────┘
          │                   │                   │
          └───────────────────┼───────────────────┘
                              ▼
  ┌────────────────────────────────────────────────────────┐
  │                 PricingService Catalog                 │
  │   Cost = (T_in * P_in + T_out * P_out) / 1,000,000     │
  │   Dual Metric: Actual Billed vs. Est. Commercial Value │
  └───────────────────────────┬────────────────────────────┘
                              │
                              ▼
  ┌────────────────────────────────────────────────────────┐
  │                 CompareResponse (JSON)                 │
  │   Normalized text, token usage, cost, and latency ms   │
  └────────────────────────────────────────────────────────┘
```

1. **Common Adapter Interface (`BaseLLMProvider`):**  
   Every provider implements `async def generate(prompt, model, system_prompt, temperature, max_tokens) -> LLMResult`. All vendor payload nuances (e.g. Anthropic's top-level `system` param, OpenAI reasoning models requiring `max_completion_tokens` and disallowing `temperature`, Google's `usage_metadata`) are normalized inside the adapter.
2. **Error Boundary Isolation:**  
   Individual coroutines are wrapped in `_safe_execute`. If a model fails (e.g. HTTP 401 Authentication, HTTP 429 Rate Limit, or SDK timeout), it returns an `LLMResult(status="error", error="...")` containing elapsed time up to the failure point. The other models finish and render normally.
3. **Decoupled Pricing Engine:**  
   Model token costs are isolated inside `PricingService`. Adapters never hardcode pricing values, simplifying rate updates and configuration overrides.

## System Execution Flow

1. **User Action:** The user inputs a prompt, selects between 1 and 6 models across OpenAI, Anthropic, and Gemini, and clicks **Compare** (`Ctrl + Enter`).
2. **Dispatch & Loading UI:** The frontend sends a `POST /api/compare` payload and immediately mounts per-model `SkeletonCard` loading placeholders.
3. **Pydantic Validation:** FastAPI validates parameters (`min_length`, valid provider literals, temperature range).
4. **Concurrent Execution:** `ComparisonService` starts a high-resolution timer (`t0 = time.perf_counter()`) and schedules async tasks concurrently with `asyncio.gather`.
5. **Inference & Token Extraction:** Each adapter invokes its respective client (`openai.AsyncOpenAI`, `anthropic.AsyncAnthropic`, `google.genai.Client`), extracts generated text, and maps vendor usage metadata to standard input/output/reasoning tokens.
6. **Financial Enrichment:** The `PricingService` calculates out-of-pocket invoice costs ($0.00 for Gemini Free Tier) and estimated commercial list values.
7. **Response & Side-by-Side Rendering:** The backend returns a unified `CompareResponse`. The UI replaces skeletons with `ResponseCard` components, displaying syntax-highlighted code, copy utilities, and performance badges (**⚡ Fastest Response**, **💰 Lowest Cost**).

## Quickstart with Docker (Recommended)

Running with Docker is the fastest, cleanest, and most reliable way to launch the entire stack. You do not need Python, Node.js, or npm installed on your host machine.

### 1. 1-Click Startup (Windows & Linux/macOS)

- **On Windows:** Double-click [`start.bat`](./start.bat) (or run `.\start.bat` in your terminal).
- **On Linux / macOS:** Run `chmod +x start.sh && ./start.sh` in your terminal.

**What the 1-click script does automatically:**
1. Verifies/creates your `.env` configuration file from template.
2. Builds and starts the Docker containers in the background.
3. Queries your network adapter and detects your local Wi-Fi / LAN IP address.
4. Displays formatted connection links for your computer and mobile devices.
5. Automatically opens `http://localhost:3000` in your default browser.

---

### 2. Command-Line Docker Startup

If you prefer using standard Docker commands:

1. Ensure your `.env` file exists:
   ```bash
   cp .env.example .env
   ```

2. Build and launch all services in detached mode:
   ```bash
   docker compose up --build -d
   ```

3. View real-time container logs:
   ```bash
   docker compose logs -f
   ```

4. Stop all running containers:
   ```bash
   docker compose down
   ```

## Cost Calculation Engine

Token costs are computed via standard pricing schedules per 1 Million tokens:

$$\text{Cost} = \frac{T_{\text{in}} \cdot P_{\text{in}} + T_{\text{out}} \cdot P_{\text{out}}}{10^6}$$

Where:
- $T_{\text{in}}$ = Count of input / prompt tokens.
- $P_{\text{in}}$ = Provider price per 1 Million input tokens.
- $T_{\text{out}}$ = Count of output / completion tokens (including reasoning tokens).
- $P_{\text{out}}$ = Provider price per 1 Million output tokens.

### Free Tier Handling
* **Google Gemini AI Studio:** Up to standard rate limits (15 RPM / 1,500 RPD), Google provides zero-cost access. The engine sets `actual_cost_usd = 0.0` and flags `is_free_tier = true`, while calculating `estimated_list_cost_usd` so users can observe economic efficiency comparisons.
* **Anthropic & OpenAI:** Always treated as billable against account balances.

## Troubleshooting & FAQ

#### 1. Why does running `python` say "Python was not found"?
On Windows 10/11, Windows App Execution Aliases intercept `python` if the installer wasn't added to your system `PATH`. Use the Python launcher instead:
```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\activate
```
Or simply run with Docker (`docker compose up --build -d`) which does not require Python on your host machine!

#### 2. Can I use the dashboard without paying for OpenAI or Anthropic credits?
**Yes!** Set `MOCK_MODE=true` in your `.env` file (or simply leave the API keys blank). The application will automatically route requests through the built-in `MockProvider`, generating realistic markdown responses, simulated latencies, and token usage for all 3 vendors.

#### 3. How do reasoning tokens affect cost?
Models such as `o1`, `o3-mini`, and `claude-3-7-sonnet-thought` generate internal reasoning tokens before producing visible text. These tokens are billed at the **output token rate**. The dashboard explicitly captures these tokens in the `reasoning_tokens` field and reflects them in the cost calculation.

#### 4. Can I add custom models or another provider (e.g. Mistral, Ollama)?
**Yes.** Implement a new class subclassing `BaseLLMProvider` in `backend/app/providers/`, register it in `backend/app/services/comparison.py`, and add its pricing rates to `backend/app/services/pricing.py`. The React frontend will automatically detect the new model from `GET /api/models`.

#### 5. Why can't other devices on my Wi-Fi open `http://<YOUR_LAN_IP>:3000`?
By default, Windows Defender Firewall blocks inbound traffic on newly bound ports if your network profile is set to "Public".
- Open **Windows Settings → Network & Internet → Wi-Fi (or Ethernet)** and set Network Profile to **Private Network**.
- If still blocked, open PowerShell as Administrator and run:
  ```powershell
  New-NetFirewallRule -DisplayName "LLM Router Dashboard" -Direction Inbound -LocalPort 3000 -Protocol TCP -Action Allow
  ```
- Alternatively, start the Cloudflare Tunnel (`docker compose --profile tunnel up -d`), which bypasses local firewall and router restrictions completely!

#### 6. How do I apply code changes when running in Docker?
Since production Docker containers bake compiled React assets and Python packages into images:
```bash
docker compose up --build -d
```
For active development with hot-module replacement (instant reloading), use the local setup with `npm run dev` and `uvicorn --reload`.

#### 7. Does the free Cloudflare Tunnel expose my local private files?
No. The Cloudflare Quick Tunnel (`cloudflared`) creates a secure, outbound-only encrypted WebSocket tunnel directly to Cloudflare edge nodes, routing only HTTP requests targeting port 80 of the frontend container. It never opens incoming ports on your home router and automatically terminates when you run `docker compose stop tunnel`.
